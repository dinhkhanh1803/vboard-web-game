# Roadmap

## Sprint 0: Foundation

- Product direction captured from the blueprint.
- Repository scaffold created.
- Firebase placeholders and closed rules added.
- Architecture, data model, security, testing, and roadmap docs added.

## Sprint 1: Core Platform Shell

- Add real package dependencies and lockfile.
- Scaffold Vite React with TypeScript.
- Add Firebase client initialization for dev environment.
- Add Authentication shell and profile placeholder.
- Add game catalog data contract.
- Add room create and join contracts with emulator tests planned first.

## Sprint 2: Connect 4 MVP

- Define `GameModule` interface.
- Add Connect 4 state, validation, apply move, and result detection tests.
- Add `submitMove` callable workflow.
- Add match screen for Connect 4.

## Sprint 3: Caro MVP

- Add Caro board model and five-in-row result tests.
- Reuse match lifecycle, timer, rematch, and history patterns from Connect 4.

## Later Sprints

- Ranking and progression.
- Admin and moderation.
- Policy pages, guide content, and safe ad placements.
- Hidden-state game support.
- O an quan, Sea Battle, Chess, and Color Cards.
