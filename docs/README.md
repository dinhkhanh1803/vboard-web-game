# Documentation Index

This folder captures the foundation decisions from the product blueprint before implementation starts.

- `control/`: the owner and AI control panel. Read this first during day-to-day work.
- `control/IMPLEMENTATION_CHECKLIST.md`: phase-by-phase work queue for AI-assisted development.
- `control/TECH_STACK.md`: accepted technology decisions for MVP.
- `foundation.md`: scaffold scope, non-goals, and ownership boundaries.
- `architecture.md`: platform-first and server-authoritative architecture.
- `firebase-model.md`: initial Firebase services, collections, and listener boundaries.
- `security.md`: security posture, anti-cheat rules, and abuse controls.
- `roadmap.md`: MVP phase order and backlog priorities.
- `testing-strategy.md`: required test layers before production.
- `decisions/`: architecture decision records.
